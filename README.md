# DateSwitcher —— Windows 定时日期切换器

一个 Windows 下的绿色小工具：按你自定义的计划，**定时自动切换系统日期**，并支持随时一键恢复真实日期。

纯 Python 标准库实现（tkinter + ctypes），无任何第三方依赖。

## 功能特性

- **三种切换动作**
  - 切换到指定日期（如 2030-01-01）
  - 相对偏移 N 天（如每天 00:00 自动 +1 天，模拟时间流逝）
  - 恢复真实日期（一键还原）
- **五种重复规则**：每天 / 工作日 / 每周（勾选星期）/ 仅一次 / 固定间隔（分钟）
- **真实时间基准**
  - 程序内部独立记录"真实时间"，系统日期被改后依然可推算真实时间
  - 支持 NTP 网络校准（默认 ntp.aliyun.com）与手动"记当前为真实时间"
- **管理员权限**：未提权时切换会失败，程序内一键以管理员身份重启（UAC）
- **任务持久化**：配置保存在 `%APPDATA%\DateSwitcher\config.json`，重启不丢失
- **运行日志**：每次切换/失败均有记录

## 运行环境

- Windows 10 / 11
- Python 3.8+（标准库即可，无需 pip 安装任何包）

## 快速开始

```bat
:: 直接运行（推荐用 pythonw 不弹控制台）
pythonw dateswitcher.py

:: 或双击 start_admin.bat —— 自动弹出 UAC 以管理员身份运行
```

> 修改系统日期需要管理员权限。普通权限下可以打开界面、编辑任务，但执行切换会失败（日志中有提示），可点击右上角「以管理员身份重启」提权。

## 使用说明

1. 在「任务编辑」区填写任务名称、触发时间（HH:MM）
2. 选择动作：
   - **切换到指定日期**：填写目标年/月/日
   - **相对偏移（天）**：填写偏移天数，如 `+1`（每天自动往后加一天）
   - **恢复真实日期**：无需参数
3. 选择重复规则并保存任务
4. 到点后自动执行；也可在列表中选中任务点「立即执行」测试

### 真实时间说明

程序首次运行时自动把当前时间记为"真实时间"基准。若首次运行时系统日期已被改过，请先点 **NTP 校准真实时间**（联网）或 **记当前为真实时间**。之后无论系统日期被切到哪一天，「恢复真实日期」都能正确还原。

## 工作原理

- 通过 ctypes 调用 Win32 API `SetLocalTime` 修改本地时间（按官方文档建议连续调用两次以修正夏令时换算）
- 真实时间基准 = 记录的 UTC 时间戳 + `time.perf_counter()` 单调流逝（不受系统时间篡改影响）
- NTP 校时为纯标准库 UDP 实现（RFC 5905 简化版）
